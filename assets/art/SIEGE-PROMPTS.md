Readable chunky silhouette at 90 pixels tall in game. Hand-placed crisp square pixel clusters, limited palette of desaturated jade teal, warm walnut, moss-gray stone and muted brass, dark navy outlines, upper-left light. Render like a refined 64x64 pixel sprite enlarged by nearest neighbor, no smooth painting, no blur, no gradients, no text, no labels, no ground tile, no background, no detached props outside the compact footprint. Whole building fully visible with transparent padding on every edge. South roof edge and doorway aligned horizontally.

## Siege-engine prompt

Use case: stylized-concept. Asset type: production animation sprite atlas for a top-down 8-bit medieval strategy game Crownfall. Create EXACT 4 columns by 2 rows, eight equal square cells, 1536x1024 canvas if possible (equal column spacing, equal row spacing; each cell may be rectangular), transparent background. Each cell contains ONE fully visible centered identical wheeled medieval siege catapult, orthographic top-down three-quarter RPG view, consistent size and pivot. Columns LEFT TO RIGHT: south/front-facing, north/back-facing, west/left-facing, east/right-facing. Row TOP: loaded idle catapult with throwing arm pulled down and a gray boulder in spoon. Row BOTTOM: same four directions with throwing arm released raised for firing pose; no projectile outside machine. All eight sprites same mechanical design: sturdy oak A-frame, four dark iron-bound wooden wheels, tension ropes, iron pivots, small jade teal armor panels, muted brass rivets; readable chunky silhouette. Crisp hand-placed pixel clusters, dark outlines, limited palette walnut wood, jade teal, dark navy iron, gray stone, parchment ropes, upper-left lighting, nearest-neighbor enlarged 48x48 sprite appearance. No crew, no text, no labels, no grid, no background or ground tile, no cast shadow outside sprite footprint. Keep every sprite inside its own cell with 15% transparent margin, no objects touching cell borders. Strict 4x2 evenly aligned atlas needed for code sampling. Horizontal and vertical orientations must be clearly distinguishable. Not isometric diagonal.
